\# Development of Pseudo-Random Pattern Generator using CPLD for Testing of LVDS Transmitter and Receiver System



\*\*Industrial Training Project | VTAD, Semiconductor Laboratory, Mohali | May–July 2026\*\*

\*\*Author:\*\* Kiran Meena, B.Tech EEE, ABV-IIITM Gwalior



\## Overview

Testing a digital system reliably requires input data that exercises every possible bit transition — not a fixed, predictable pattern, but something that closely resembles real-world data. This project develops a Pseudo Random Pattern Generator using a CPLD (Altera MAX EPM7256AE) to test and characterize a Low Voltage Differential Signalling (LVDS) transmitter and receiver pair.



\## Key Results

\- 10-bit LFSR-based pseudo-random pattern generator

\- Design used only 26/256 macrocells and 19/164 usable I/O pins

\- LVDS pair operated error-free from 6 MHz to 40 MHz

\- Bit errors observed at 50 MHz, establishing the reliable upper operating limit

\- Propagation delay remained stable at \~4.0–4.4 ns across all test frequencies



\## Tools Used

\- CPLD: Altera MAX EPM7256AEQC208-7

\- Simulation: ModelSim-Altera 10.1d

\- Synthesis: Quartus II 13.1

\- Language: VHDL
